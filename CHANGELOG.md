# Changelog

All notable changes to MycoMonitor will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-05-01

### Added
- Initial release
- Humidity monitoring and control system
- Zigbee sensor integration
- Smart plug control
- Logging system
- Configuration management
- Safety features and failsafes
- Testing framework
- Development environment
- Documentation

### Changed
- Restructured project from original script
- Improved error handling
- Enhanced logging capabilities
- Updated GPIO pin management

### Deprecated
- Old script-based approach

### Removed
- Direct state file manipulation
- Hard-coded configurations

### Fixed
- GPIO cleanup on shutdown
- Sensor reading validation
- Error handling in network operations

### Security
- Added proper GPIO access controls
- Improved error handling
- Added logging for security events

## [0.1.0] - 2025-03-19

### Added
- Initial prototype script
- Basic humidity control
- Simple state management
