## 💡 What it does:
Simulates realistic sensor readings for two sensors (sensor1, sensor2).

Saves them to state.json every 60 seconds (you can change this).

Useful for offline or test setups without actual Zigbee sensors.

## ✅ Usage:
Save it as simulate_state_json.py in the same directory as your main script.

Run it with:

bash
```
python3 simulate_state_json.py
```
Let it run in the background or in another terminal window.
