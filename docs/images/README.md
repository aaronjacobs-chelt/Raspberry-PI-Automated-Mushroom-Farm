## Creating Technical Diagrams

The ASCII art diagrams in this directory are designed to be:
1. Readable directly in GitHub without any special tools
2. Printable for reference during hardware assembly
3. Convertible to proper image diagrams if needed

If converting these ASCII diagrams to PNG/SVG images:
- Maintain the same structure and information
- Use consistent styling and colors
- Add to this directory with the same filename but different extension

## Adding Images

When adding new images to this directory:

1. Use descriptive filenames that clearly indicate the content
2. Optimize images for web use (compress to reduce file size)
3. Use PNG format for logos and diagrams, JPG for photos
4. Include appropriate attribution if using third-party images
5. Update this README.md when adding new images
